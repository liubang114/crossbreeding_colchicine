# 杂交育种：秋水仙素 Crossbreeding: Colchicine

**杂交育种**的附属模组。需要主模组同时安装。

---

## 用途

现实中秋水仙素能让染色体数目翻倍。游戏里对应：**把单倍体配子翻倍成纯合二倍体**。

例：

- 配子 `aBcdEF` → 种子 `aaBBccddEEFF`
- 配子 `AbCdEf` → 种子 `AAbbCCddEEff`

育种价值：让隐性性状**一步纯合**，省去多代自交。

---

## 酿造秋水仙素溶液

| 位置 | 物品 |
|------|------|
| 下方 | 药水瓶 |
| 上方 | 铃兰 |

产出：**秋水仙素溶液**。

---

## 使用

工作台放入：

- 1 个秋水仙素溶液
- 1 个配子（雌或雄均可）

产出：**纯合杂交种子**，合成后**返还空玻璃瓶**。
