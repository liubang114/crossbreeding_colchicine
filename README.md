# 杂交育种：秋水仙素

**杂交育种**的附属模组。添加酿造配方生产秋水仙素溶液，可将单个配子的基因型翻倍成纯合种子。

---

## 特性

- **酿造配方**：铃兰 + 水瓶 → 秋水仙素溶液
- **新合成配方**：秋水仙素溶液 + 1 个配子 → 纯合杂交种子
- **合成后返回空瓶**
- **加速育种**：一步锁定隐性性状

---

## 原理

配子是单倍体（每个基因只有一个等位基因），秋水仙素把它翻倍成纯合二倍体：

| 配子 | 秋水仙素处理后 |
|------|--------------|
| `aBcdEF` | `aaBBccddEEFF` |
| `AbCdEf` | `AAbbCCddEEff` |

这对纯合**多穗**、**高饱食**、**高饱和**、**少壳**、**生长旺盛**等隐性性状特别有用。
